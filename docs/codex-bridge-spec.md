# Техническое задание: связующий агент PPR-Control ↔ Codex

## Цель

Основной администратор отправляет текстовое задание и до трёх вложений из PPR-Control. Локальный агент на рабочем компьютере получает задание, запускает установленный Codex и возвращает в приложение статус и итоговый ответ.

## Полный сценарий

1. Только основной администратор видит окно «Задания Codex».
2. Приложение сохраняет задание на сервере со статусом `new`.
3. Локальный агент авторизуется отдельным секретным токеном и атомарно забирает одно задание.
4. Сервер выдаёт аренду задания на три минуты. При обрыве просроченное задание можно забрать повторно.
5. Агент скачивает разрешённые вложения только с домена PPR-Control.
6. Агент запускает `codex exec` в локальном Git-репозитории с режимом `workspace-write`.
7. Агент продлевает аренду во время работы и отправляет статусы `analyzing`/`working`.
8. Итог Codex возвращается в PPR-Control как `completed`; ошибка — как `failed`.
9. Основной администратор получает личное push-уведомление об изменении статуса.
10. Агент запускается при входе пользователя Windows и не публикует секрет в GitHub.

## Ограничения безопасности

- `CODEX_AGENT_TOKEN` хранится только в Render и локальном файле с ACL текущего пользователя.
- Маршруты агента недоступны без токена.
- Задания может создавать только основной администратор.
- Агент работает в `workspace-write`, без `danger-full-access`.
- Вложения принимаются только из хранилища PPR-Control.
- Публикация, merge и внешние изменения не выполняются без прямого указания пользователя.

## Административная панель без редактирования кода

Отдельный следующий этап — дать администратору формы для небольших исправлений без обращения к ИИ: названия, оборудование, роли, маршруты уведомлений, чек-листы, сроки, восстановление записей, диагностика и журнал изменений.

## Критерии готовности

- тесты API подтверждают запрет доступа без токена;
- heartbeat переводит индикатор агента в состояние «подключён»;
- тестовое задание проходит `new → accepted → analyzing/working → completed`;
- результат отображается в приложении;
- после перезапуска Windows агент подключается автоматически.
