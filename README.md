# ППР Контроль

Производственная PWA для ППР, журналов оборудования, QR-обходов,
замечаний, простоев, нарядов-допусков и контроля сотрудников.

## Требования

- Node.js 18 или новее;
- npm;
- PostgreSQL — только для проверки серверного режима. Без строк подключения
  сервер безопасно использует локальное JSON-хранилище в каталоге `data/`.

## Чистый локальный запуск

```powershell
git clone https://github.com/hofmankz100-bot/ppr-control.git
cd ppr-control
npm ci
npm run check
npm start
```

После запуска приложение доступно по адресу:

```text
http://localhost:8080/
```

`npm run check` сначала собирает production-файлы, затем запускает весь набор
автоматических тестов. Тесты используют изолированные временные данные и не
должны подключаться к рабочей базе.

## Переменные окружения

Основные параметры перечислены в `.env.example`. Файл служит шаблоном и не
содержит настоящих паролей. Node.js не загружает его автоматически: значения
задаются в Render либо в текущей оболочке перед запуском.

Для обычной локальной разработки переменные окружения не обязательны.
Никогда не используйте production-строки подключения при запуске тестов.

## Основные возможности

- список оборудования;
- узлы оборудования;
- график по дням месяца;
- чек-листы ТО, ТО-2, ТО-3;
- комментарии и отметка устранения;
- красная мигающая сигнализация по оборудованию при открытом замечании;
- серверная синхронизация с PostgreSQL и локальный резервный режим;
- хранение состояния устройства через localStorage и IndexedDB;
- manifest и service worker для PWA.

Для установки на iPhone или Android приложение нужно разместить на HTTPS-адресе.
После этого:

- iPhone: Safari -> Поделиться -> На экран Домой;
- Android: Chrome -> Установить приложение.
